# Netflix Data Science Internship Project

## 📌 Project Overview

This repository contains my Data Science internship project based on the Netflix Titles dataset.

The project covers four practical Data Science tasks involving data cleaning, exploratory data analysis, recommendation systems, and trend prediction.

## 🎯 Completed Tasks

### Task 1 — Data Cleaning & Preprocessing

* Loaded the Netflix dataset using Pandas
* Identified missing and duplicate records
* Handled missing values
* Transformed categorical and date-related data
* Created a clean dataset for further analysis

### Task 2 — Exploratory Data Analysis

* Analyzed dataset structure and statistics
* Studied Netflix content distribution
* Analyzed top countries and categories
* Created visualizations
* Identified important content trends

### Task 3 — Recommendation System

* Selected relevant content features
* Applied text preprocessing
* Used TF-IDF vectorization
* Calculated cosine similarity
* Generated content recommendations
* Evaluated recommendations using category overlap

### Task 4 — Trend Prediction Analysis

* Prepared yearly Netflix content data
* Analyzed historical content trends
* Built a Linear Regression forecasting model
* Predicted content counts for 2022–2026
* Visualized historical and predicted trends
* Interpreted the forecasting results

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## 📊 Dataset

The project uses the Netflix Titles dataset containing information about Netflix movies and TV shows, including title, type, country, release year, rating, duration, and categories.

## 📈 Key Results

* The cleaned dataset contains 8,790 Netflix titles.
* Movies were more numerous than TV Shows.
* The dataset showed a strong increase in content volume after the 2000s.
* The highest number of titles in the analyzed release-year data was recorded in 2018 with 1,146 titles.
* The Linear Regression model predicted a slight increase in content counts from 383 titles in 2022 to 410 titles in 2026.

The purpose of this project was to apply practical Data Science concepts to a real-world dataset and demonstrate skills in data preprocessing, exploratory analysis, recommendation systems, and predictive analytics.
